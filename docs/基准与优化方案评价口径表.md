# 基准与优化方案评价口径表

> 项目：面向超大城市的末端配送协同网络规划方案设计  
> 版本：V1.0（讨论稿）  
> 日期：2026-09-19  
> 适用范围：论文第6—10章、决策支持平台、模型验证与答辩展示

## 1. 编制目的

本口径表用于统一“优化前”和“优化后”的方案定义、输入条件、评价指标、计算公式及展示方法，保证论文、数据表、后端接口和前端看板使用同一套结果。

本阶段只确定评价规则，不直接采用项目中现有的硬编码结果。所有结果数字应在基础数据版本冻结后，由同一评价程序根据模型输出自动计算。

## 5. 改善率计算规则

### 5.1 越低越好的指标

适用于里程、时间、工时、成本、碳排放、积压和满柜时长：

`改善率 = (基准值 - 优化值) / 基准值 × 100%`

### 5.2 越高越好的指标

适用于准时率、覆盖率、履约率、处理效率和承载率：

`改善率 = (优化值 - 基准值) / 基准值 × 100%`

### 5.3 特殊情况

- 基准值为0时，不计算百分比，只报告绝对变化。
- 人数、车辆数、满柜社区数等离散指标，同时报告绝对变化和比例变化。
- 路径距离保留2位小数；时间保留1位小数；金额统一到元计算、展示时可换算为万元；比例保留1位小数。
- 不得将不同版本或不同需求总量下的数字直接计算改善率。

## 6. 实验与仿真执行规则

1. **冻结输入版本**：每轮正式对比记录数据文件版本、需求版本、成本参数版本和代码提交号。
2. **一次输入生成三方案**：S0、S1、S2从同一输入对象分别计算，不手工录入结果。
3. **统一距离矩阵**：优先采用高德/真实路网规划距离；缺失时才使用路网最短路；直线距离乘绕行系数只能作为低可信度备用值。
4. **区分完成时间和人工工时**：完成时间取最后任务完成时刻；人工工时为所有人员工时之和。
5. **随机过程可复现**：记录随机种子。若使用泊松到达、随机取件或随机启发式，正式结果至少重复30次，报告均值和95%置信区间。
6. **确定性模型不得伪装成随机仿真**：若只使用固定比例推进，应称为“确定性情景推演”；只有实际采样随机事件时才能称为随机离散事件仿真。
7. **约束先于结果**：存在硬约束违反时，方案状态只能标记为“不满足约束”，不得继续宣称最优。
8. **结果不可硬编码**：README、论文、接口和看板中的数字必须来自同一评价结果文件或接口。
